What We Handle

Everything billing — so you ship your product

SubService is a dedicated billing back-office for SaaS products. You call our API; we handle Stripe, invoices, dunning, renewals, and revenue analytics. Your team never touches payment infrastructure.

Plan Management

Versioned plan catalog with monthly and annual pricing, free tiers, trials, and add-on packs. Change prices without touching code.

Stripe Checkout

Hosted Stripe Checkout pages — your users never see your server. PCI compliance handled. Your app just redirects and receives the result.

Entitlement Gates

One API call returns the full entitlement snapshot for a user — plan, status, limits, and feature flags. Gate any route in a single if-statement.

Dunning & Recovery

Automatic retry schedule on failed payments: day 0, 3, 7, 14. Suspension and reinstatement handled by SubService — no code on your side.

Invoicing

Invoices generated and stored automatically on every billing cycle. Full payment history available via API or GMA-AI admin dashboard.

Revenue Analytics

MRR, ARR, churn rate, new subscriptions, AI usage — live dashboard and API endpoint. Know your numbers without building the infrastructure.

AI Usage Metering

Record AI actions against monthly limits. Idempotent event API prevents double-counting. Hard-cap enforcement with HTTP 429 when limits are exhausted.

Multi-Tenant Isolation

Every partner product is a separate tenant with its own plan catalog, pricing, and customer data. Row-Level Security enforced at the database — cross-tenant access is impossible by design.

Integration

Up and running in under two weeks

SubService is a service-to-service API. Your app calls it; SubService handles the rest. There is no Stripe SDK to integrate, no webhook infrastructure to build, and no payment data to store.

  1. 1
    Fill in the Payment Matrix Questionnaire Tell GMA-AI your plan tiers, prices, module access rules, and AI limits. We seed your catalog in SubService — no code required from you.
  2. 2
    Receive your API key and tenant ID GMA-AI provisions your tenant and delivers credentials securely. Set four environment variables in your app — that is the entire configuration.
  3. 3
    Wire registration and entitlement checks On new user signup, call POST /subscriptions. On any gated action, call GET /subscriptions/{user}/status and check the returned entitlements object. Reference client code is available.
  4. 4
    Add a pricing page and checkout redirect Fetch live plan data from our catalog API. When a user upgrades, SubService returns a Stripe Checkout URL — redirect the browser to it. Done.
  5. 5
    Joint dress rehearsal — then go live GMA-AI runs a 9-step end-to-end rehearsal with your team: registration, upgrade, gate enforcement, suspension, cancel, and decline paths. All steps pass — you go live.
